# Fresh Car Hamm — Ultimate Website

Next.js Website für Vercel. Keine UI-Bibliotheken, keine schweren Animation-Libraries und keine externen Bild-Abhängigkeiten.

## Lokal starten

```bash
npm install
npm run dev
```

Dann `http://localhost:3000` öffnen.

## Kostenlos auf Vercel veröffentlichen

1. Ordner in ein GitHub-Repository hochladen.
2. Bei Vercel auf **Add New → Project**.
3. GitHub-Repository auswählen.
4. **Deploy** drücken.

## Später echte Bilder einsetzen

Lege Fotos unter `public/media/` ab, z. B.:

- `hero.webp`
- `gallery-01.webp`
- `gallery-02.webp`
- `before.webp`
- `after.webp`

Danach können die Platzhalter in `app/page.jsx` sehr einfach ersetzt werden.

## Später Video einsetzen

Lege die Datei z. B. als `public/media/showreel.mp4` ab. Der Showreel-Bereich ist bereits im Layout vorbereitet. Für schnelles mobiles Laden sollte das Video vorher weboptimiert/komprimiert werden.
